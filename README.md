# 🌍 Oratorlx - Interactive Language Learning & Words Game

> A modern, interactive web application designed to make language learning fun and engaging through structured classes, flashcards, quizzes, and vocabulary practice.

---

## ✨ Features

* **📚 Structured Lessons:** Categorized learning paths (e.g., beginner classes, level-based modules).
* **⚡ Interactive Flashcards:** Flip and practice key vocabulary with visual support.
* **🎯 Practice Quizzes:** Test your knowledge and track your progress.
* **🌐 Multi-Language Support:** Easily switch between languages (such as Korean and more).
* **📱 Responsive Design:** Clean, modern user interface optimized for seamless browsing across devices.

---

## 🛠️ Built With

This project is built using pure, lightweight web technologies:
* **HTML5** – Structured page layouts and semantic markup.
* **CSS3** – Modern styling, layouts, and responsive design.
* **JavaScript (Vanilla)** – Core application logic, interactivity, and DOM manipulation (`app.js`).
* **Data Management** – Structured local datasets (`data.js`).
